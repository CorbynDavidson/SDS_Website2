# Published wording overrides

Owner-approved page edits are committed here as JSON by the website publisher.
Each file is named with the SHA-256 of the page path and records the original and
replacement text for recognised wording fields. The build rejects stale fields,
unknown pages and markup injection. Captured SDS source and SEO metadata remain
unchanged. Overrides are applied after the migration baseline is validated.

Do not edit generated page files to publish wording. Change or revert the
corresponding override through a checked pull request.
